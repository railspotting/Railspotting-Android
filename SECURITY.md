# Security

Please report security problems privately, not in a public issue: use **Report a vulnerability**
on this repository's Security tab (GitHub private vulnerability reporting).

Useful to include: what is affected (the app, its Rust core, or how it talks to the RailSpotting
service), how to reproduce it, and what an attacker could do. You'll get an answer within a few
days.

In scope: the app and the code in this repository, including request signing, the stored device
key, the self-update check, and USB handling. The RailSpotting service (railspotting.com) is not
open source; problems found there are welcome through the same channel.

Please don't test against other people's receivers or accounts.
